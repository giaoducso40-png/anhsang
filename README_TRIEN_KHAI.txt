CHỦ ĐỀ ÁNH SÁNG KHTN 9 — CÔ NGUYỄN THỊ LAN ANH

1. Đưa toàn bộ nội dung của thư mục này lên thư mục xuất bản GitHub Pages.
   Tệp index.html phải nằm ngay tại thư mục xuất bản; giữ nguyên tên tệp và thư mục shared.
2. Mở trang từ đường link GitHub Pages, nhập hồ sơ học sinh rồi mở bài tập.
   Kết quả của 18 bài tập được lưu trong trình duyệt trên thiết bị đang dùng.
   Xóa dữ liệu trình duyệt hoặc đổi thiết bị có thể làm mất dữ liệu cục bộ.
3. Bảng giáo viên ở trang tổng và trong từng bài chỉ đọc dữ liệu trên cùng trình duyệt.
   Việc cùng mở một đường link chưa tự đồng bộ kết quả giữa các thiết bị.
4. Mật khẩu giáo viên "admin" trong phiên bản này chỉ khóa giao diện cục bộ.
   Mã trang công khai trên GitHub có thể được xem bởi người truy cập; không dùng
   cơ chế này để bảo vệ dữ liệu tập trung khi triển khai Firebase.
5. API chatbot trong thư mục api là hàm dành cho môi trường hỗ trợ máy chủ
   (ví dụ Vercel). Trên GitHub Pages, trợ lý dùng câu trả lời dự phòng có sẵn.

Khi tạo cơ sở dữ liệu chung ở bước sau, cần thay bộ lưu cục bộ bằng Firebase,
thiết lập tài khoản giáo viên và quy tắc phân quyền trước khi thu dữ liệu thật.
